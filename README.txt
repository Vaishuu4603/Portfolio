VAISHNAVI WALUNJ PORTFOLIO
=========================
A responsive, static HTML/CSS/JavaScript portfolio inspired by the dark navy and green style shown in your reference video. It does not use any photos or photo placeholders.

FILES
- index.html: page content
- style.css: design and responsive layout
- script.js: mobile menu and animated role text

READY TO PREVIEW / UPLOAD
1. Extract this ZIP.
2. Open index.html in a browser to preview.
3. Upload index.html, style.css, and script.js to the root of a GitHub repository.
4. In GitHub, open Settings > Pages, select deploy from the main branch and root folder, and save.

Before publishing, review your contact details and confirm you want them public. Project cards currently describe projects from your CV; add GitHub repository/demo links if you want visitors to open the code.
